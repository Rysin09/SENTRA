# SENTRA — Implementation Phases

## Phase 0 — Foundation
Python 3.12+, repository structure, configuration, Streamlit shell, PostgreSQL, README.

## Phase 1 — Text Intake
Case creation, consent, text input, validation and persistence.

## Phase 2 — Text/NLP Screening
Text normalization, indicator extraction, eight dimensions, confidence, explanation and operational category.

## Phase 3 — Voice Pipeline
Audio upload, validation, ASR, language handling, acoustic feature extraction and quality checks.

## Phase 4 — Multimodal Fusion
Text + audio + context features, missing-modality mask and combined assessment.

## Phase 5 — Safety Layer
Confidence thresholds, insufficient-data state, invalid-output handling, AI failure fallback and prompt-injection protection.

## Phase 6 — Human Review
Reviewer dashboard, evidence view, override, notes, review status and audit.

## Phase 7 — Testing & Hardening
Unit/integration tests, failure tests, synthetic cases, privacy and security checks.

## Phase 8 — SIH Demo Readiness
Stable UI, demo dataset, documentation, architecture diagrams, reproducible setup and demo script.

## Future Research
Broader language support, external validation, fairness evaluation, calibration, workflow integration and scalable deployment.
Do not claim clinical validation or production readiness before such work is actually completed.
